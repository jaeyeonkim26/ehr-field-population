Clinical NLP · Structured Data · Evidence Verification

Validation-Guided Selective Adaptation and Evidence-Grounded Verification for Automated Population of Structured EHR Fields from Clinical Notes

A field-aware pipeline that focuses adaptation where baseline extraction is weak and checks uncertain predictions against the patient's own clinical record.

Researcher Jaeyeon Kim Degree Master's Thesis Stage Manuscript in Preparation
02

Research Question

How can heterogeneous clinical narratives be converted into structured EHR fields without applying the same correction strategy everywhere?

Problem

EHR fields differ in definition, label space, frequency, and extraction difficulty. Uniform regeneration can alter predictions that were already stable.

Response

Measure field-level behavior, adapt selected targets, and use patient-specific evidence to verify the values that remain uncertain.

03

System

Proposed processing path

One baseline, two targeted refinement paths

INPUT Clinical Notes Admission and progress records
BASE Hybrid Prediction Codebook-guided structured output
GATE Validation-Guided Selection Field-level vulnerability analysis
Correction path Selective LoRA Adapt and merge selected fields
Evidence path Clinical Verification Retrieve evidence and judge each candidate
OUTPUT Structured EHR Field-level final values
04

Design Principles

A

Measure Before Adapting

Field-level development metrics identify where additional modeling effort is justified.

B

Preserve Stable Predictions

Baseline and adapted outputs are combined with policies selected on validation data rather than replacing every field uniformly.

C

Return to the Record

Verification uses retrieved clinical evidence, field descriptions, and allowed values before revising a prediction.
